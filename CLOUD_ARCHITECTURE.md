# Cloud Architecture Overview

## Project Type
**Online / Cloud-Based SaaS Platform**

This project is explicitly designed and deployed as a **cloud-native, online web application**. It is NOT an offline, local, or desktop application.

## Technologies
- **Frontend**: Cloud-hosted React (Vite) Single Page Application (SPA).
- **Backend & Database**: Supabase (PostgreSQL, Edge Functions, Auth, Storage) hosted in the cloud.
- **AI Integration**: Integration with cloud AI APIs (e.g., OpenRouter, OpenAI) for real-time natural language processing and legal analysis. Webhooks are used for external service communication.

## Infrastructure Highlights
- Scalable cloud infrastructure.
- Zero local processing requirements for clients.
- Always online and accessible from any modern web browser.
- Cloud storage for PDFs, images, and audio.
